Terms of Service

Acceptable use

Use SHAN API HUB only for lawful development and testing. Do not abuse the service, attempt unauthorized access, interfere with other users, or send excessive traffic.

API data

API responses contain data supplied by the platform administrator or sources the platform is authorized to use. You are responsible for checking that your use complies with applicable law and third-party rights.

Accounts and keys

Keep passwords and API keys private. You are responsible for activity performed with your credentials. Revoke a key if you believe it has been exposed.

Availability

Service availability, quotas and plan features may change. Paid plans are activated for the duration displayed at purchase.

Contact

Contact the SHAN API HUB administrator through the support channel provided by the operator.

POLICIES

Privacy Policy

Information collected

The service stores account name, email, password hash, API key hashes, plan information, coin transactions and API usage logs needed to operate the platform.

How information is used

Information is used to authenticate users, provide API access, enforce quotas, prevent abuse and maintain service reliability.

API keys

Raw API keys are shown once when created. The platform stores a cryptographic hash rather than the original key.

Security and retention

Reasonable technical safeguards are used. Usage and transaction records may be retained for operational, security and accounting purposes.

Your choices

Do not share your credentials. Contact the operator to request account assistance or clarification about stored information.
